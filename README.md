# 마이 개러지 (My Garage)

차량 정비 관리 모바일 웹앱. 빌드 없이 정적 파일만으로 동작하고, 데이터는 브라우저(localStorage)에 저장됩니다.

## 실행

```bash
cd car_maintenance
python3 -m http.server 8000
```

- PC: http://localhost:8000
- 폰(같은 Wi-Fi): `ipconfig getifaddr en0` 로 맥 IP 확인 후 `http://<IP>:8000`
- 예시 데이터로 보기: 주소 뒤에 `?demo` (차량이 없을 때만 동작)

폰 브라우저에서 "홈 화면에 추가"하면 앱처럼 전체화면으로 실행됩니다.
(오프라인 캐시는 HTTPS 또는 localhost에서만 동작 — GitHub Pages / Netlify 등에 올리면 완전한 PWA로 사용 가능)

## 구조

| 파일 | 내용 |
|---|---|
| `js/data.js` | 브랜드·차종·색상·연료, 정비 항목 기본 주기 |
| `js/car.js` | 차종/색상별 자동차 SVG 생성 |
| `js/app.js` | 화면, 주행거리 예측, 정비 일정 계산, 저장 |
| `css/style.css` | 스타일 (화이트 + 블루) |
| `sw.js`, `manifest.webmanifest` | PWA (홈 화면 추가, 오프라인) |

## 계산 방식

- **예상 주행거리**: 최근 1년 내 주행 기록(직접 입력 + 정비 기록의 km)으로 하루 평균을 구해 마지막 입력 이후 일수만큼 더함. 기록이 부족하면 차량의 "월 평균 주행거리" 사용. 주행거리 탭에서 직접 설정으로 고정 가능.
- **다음 정비**: 해당 항목의 마지막 정비 기준 `+ 거리 주기` / `+ 기간 주기` 중 먼저 도래하는 쪽. 진행률 85% 이상 또는 30일 이내면 "곧 점검", 초과 시 "점검 필요".
